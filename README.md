# Youssef Ashraf ElNaggar — DevOps & Cloud Infrastructure Portfolio

> A high-performance, dark-mode, interactive engineering portfolio designed specifically for **DevOps & Cloud Infrastructure Engineers**. Built with clean HTML5, modern vanilla CSS3, and ES6 modular JavaScript. Ready for instant deployment on [Vercel](https://vercel.com).

## 🚀 Key Features

- **Interactive Cloud Terminal (`>_ CLI`)**: Simulated DevOps terminal where recruiters can type `help`, `skills`, `projects`, `kubectl get pods`, `docker stats`, `metrics`, `deploy`, or `cat resume.txt`.
- **Live Simulated CI/CD Pipeline**: Real-time pipeline visualizer showing automated commits, multi-stage Alpine Docker builds, Terraform IaC, and zero-downtime rollouts with a re-run trigger.
- **Architecture Blueprints (Native `<dialog>` Modals)**: Deep dive into the architecture of all 4 flagship production projects with system topology diagrams.
- **Quantifiable Impact Metrics Bar**: Highlighting your `97.5%` container size reduction, `200+` CI nodes managed, `40%` manual effort slashed, and `3.95` GPA with highest honors.
- **Dynamic Cloud Particle Mesh**: Smooth HTML5 canvas rendering of interconnected cloud nodes reacting to cursor movement.
- **Category Filterable Tech Arsenal**: Filter between Cloud & Orchestration, CI/CD & Automation, Observability & Reliability, and Scripting & Data.
- **Full Printable Executive Resume Modal**: Complete with a 1-click **Print / Save PDF** button.
- **Instant Clipboard Actions**: 1-click email & phone copying with toast feedback.
- **Vercel Zero-Config Deployment**: Optimized with security headers, clean URLs, and static asset caching in `vercel.json`.

## ☁️ Deploying to Vercel in 2 Minutes

### Method 1: Via GitHub (Recommended for automatic CI/CD)
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "feat: Initial DevOps portfolio"
   ```
2. Create a new repository on your GitHub (e.g. `devops-portfolio`) and push:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/devops-portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
4. Import your `devops-portfolio` repository.
5. Keep default settings (Framework: *Other*, Root Directory: `./`).
6. Click **Deploy**!
   Your site is now live with global edge CDN, HTTPS, and continuous deployments on every `git push`!

### Method 2: Via Vercel CLI
If you have Vercel CLI installed:
```bash
npx vercel
```
Follow the 3 quick prompts and your portfolio will be deployed instantly!
